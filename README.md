## Preguntas

**¿Para qué sirve Git?**

Git sirve para controlar las versiones de un proyecto, guardar los cambios realizados y poder consultar su historial.

**¿Qué función tiene GitHub Actions?**

GitHub Actions permite automatizar tareas del repositorio, como comprobar, construir y desplegar la web.

**¿Qué elementos SEO has incorporado en tu web?**

He incorporado títulos SEO, meta descripciones, una correcta estructura de encabezados con `h1` y `h2`, y texto alternativo (`alt`) en las imágenes.
